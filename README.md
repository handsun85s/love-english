# 森语探险 · Little English

给小学低年级孩子的动物自然主题英语平台。用短故事、声音和图像帮助理解，再邀请孩子完成任务、尝试一句表达。每次约 5–8 分钟是试用起点，孩子可以随时结束。

[打开森语探险](https://handsun85s.github.io/love-english/)，无需登录，可在手机、平板或电脑上使用。

## 本地运行

安装 Node.js 22 或更新版本，将仓库克隆到本机后，在仓库目录执行：

```sh
npm run dev
```

无需安装第三方依赖。打开终端输出的本机地址，默认是 `http://127.0.0.1:5188`；端口被占用时可通过环境变量 `LITTLE_ENGLISH_PORT` 指定其他端口。

## 发布到 GitHub Pages

可直接部署 `docs/` 里的静态网站，不需要构建或后端服务：

1. 将完整仓库推送到 GitHub 的 `main` 分支。
2. 打开仓库 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择 **main** 分支和 **/docs** 目录，保存。
5. 等待 Pages 部署成功，使用 GitHub 返回的公开网站链接。

页面脚本、插图与英语音频都使用相对路径，支持 GitHub Pages 项目子目录。`docs/.nojekyll` 会禁用不需要的 Jekyll 处理。`docs/` 也可部署到其他静态网站服务。

## 当前可用体验

- 10 个自由选择的动物自然场景、30 个词、10 句表达；新增池塘朋友、天气、花丛昆虫和小熊饮品店。
- 小故事 → 点图听词 → 听音找图 → 句子排序（可跳过）→ 自愿说一句 → 生活动作任务。
- 森林小小快递员：听 6 张食品与饮品订单，按意思送东西；可重听、看提示、重试。
- 声音翻翻乐：把动物的声音卡与图片卡配成 4 对，每轮从 6 位动物朋友中选出 4 位；不计时、不扣分，支持词语提示。
- 内置 73 段英语合成音频，支持慢速；加载失败时尝试设备英语朗读。
- 错误后可以重试或查看文字提示；不开设排行榜、倒计时或发音自动评分。
- 简化间隔复习：首次正确隔天，再按 3、7、14 天延后；错项当天再见。同一天重复练习不反复升级，提前自由复习不提前升级。
- 词卡收藏、家长记录、名字和语速设置、记录导出与二次确认清空。
- 响应式界面、键盘导航、模态焦点约束与减少动效支持。

## 数据与边界

学习记录仅保存在当前设备、当前浏览器的 localStorage 中，暂不跨设备同步。不同网站域名的记录也不互通。清理数据或使用隐私模式可能造成丢失，保存失败时页面会提示。导出文件用于留档，当前版本不支持导入。

游戏记录与课程和词汇记录独立；玩完游戏不代表掌握其中的词。同一天重复完成游戏不会反复增加记录。升级保留原有课程、收藏、复习和设置。

平台不申请麦克风权限，不记录儿童声音。优先播放网站内置音频；备用朗读取决于设备或浏览器，部分语音服务可能联网。完成过、见过和自报开口都不等于掌握；平台尚未进行学习效果验证，也未包含完整自然拼读课程。

课程、界面和森林插画为本项目原创。英语音频使用 Microsoft Zira 英语合成声音生成，并非真人录音。没有复制参考项目的代码、课程或美术；参考项目各自的许可不代表本仓库的授权条件。

## 重新生成英语音频

音频文件已经包含在 `docs/audio/` 中，普通运行或部署不需要 Windows。若修改课程后需要重新生成音频，在装有英语系统语音的 Windows 环境执行：

```powershell
node scripts/speech-manifest.mjs
./scripts/generate-audio.ps1
```

生成脚本依赖 Windows 的 `System.Speech`。发布前请重新执行检查与测试。

音频清单会保留已发布的文件名，避免旧缓存中的声音被误用于新单词；生成脚本默认仅补充缺失的音频。若需用相同文件名重新生成全部语音，执行 `./scripts/generate-audio.ps1 -RegenerateAll`，并在发布时更新资源版本。
