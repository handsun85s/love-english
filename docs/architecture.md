# 森语探险：实现与维护

## 技术选择

当前是无第三方运行时依赖的静态网站，适合公开链接直接访问；GitHub Pages 从 `main` 分支的 `docs/` 发布。站点使用相对资源路径以支持项目子目录。此设计不依赖账号或服务器，但不能跨设备同步学习记录。

## 模块与数据流

- `index.html` 加载 `styles.css` 和 `app.js`，`forest.svg` 提供森林插画。
- `content.js` 保存故事、词汇、句子和动作内容；`audio-map.js` 将英文文本对应到 `audio/` 中的音频。
- `app.js` 负责界面、交互、声音、保存提示和各流程的组织。声音优先使用站内音频，失败时尝试浏览器英语朗读；备用朗读依赖设备。
- `playground.js` 包含两个游戏的配置和配对、订单规则；游戏记录与课程和词汇记录分开。
- `engine.js` 管理进度、复习日程、数据规范化及读写。进度通过浏览器 `localStorage` 保存；其版本键为 `little-english:progress:v1`。打开时发现记录损坏、版本不支持或关键结构异常，会保留原文并暂停保存。家长可以先导出留档，再通过二次确认清空；清空前会检查原记录是否变化。每次保存也会与本页面读取到的版本比较，发现其他页面更新后暂停写入并提示。

## 运行和验证

在仓库根目录使用 Node.js 22 或更新版本：

```sh
npm run dev
npm run check
npm test
```

开发服务器默认地址为 `http://127.0.0.1:5188`；可设置 `LITTLE_ENGLISH_PORT` 使用其他端口。浏览器检查建议使用独立端口，以免改动现有网站或设备上的学习记录。自动测试不能代替真实浏览器及孩子试用。

## 约束

记录属于当前浏览器和域名，清理数据或隐私模式可能导致丢失；导出仅供留档，当前不可导入。浏览器本地存储的比较与写入并非原子操作，极短时间同时写入仍可能产生竞态；未刷新的旧版页面也没有新保护。建议同一浏览器只打开一个学习页面。网站不申请麦克风权限，不记录儿童声音。内置声音是合成语音，备用朗读可能依赖在线语音服务。修改内容或音频时应保留已发布音频文件名，避免缓存错配；详细生成与发布步骤见根目录 README。发布时应核对浏览器缓存版本及 Pages 构建结果。
