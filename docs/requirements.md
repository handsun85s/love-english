# 森语探险：需求与验收

## 目标和场景

**明确需求：**面向小学二年级、从一年级开始接触英语的孩子；孩子觉得每天读英语和记用法有些吃力，家长希望通过兴趣帮助学习。孩子喜欢动物与自然，通常自己使用平板或电脑；网站通过公开链接随时访问。家长希望视觉和交互达到儿童精品产品的水准，并倾向做深现有核心体验。

**核心流程：**当低年级孩子想自己玩一小会儿时，选择一个动物或自然故事，听声音、认图片并完成轻量任务，得到可见的完成反馈，并可以下次继续使用。

**可逆假设：**以短故事和图片、声音为主要入口；一次约 5–8 分钟是试用起点而非要求。开放探索、低压力的反馈可能比计时或排名更适合这一场景。是否足够有趣、孩子能否独立使用以及是否真正帮助学习，都需要孩子实际试用验证；完成任务不等于掌握英语。

## 现有范围

已有 10 个动物自然场景、30 个词、10 句表达，以及听订单送物品和声音图片配对两个游戏。课程包含故事、词卡、听辨、句子排序、可选开口和动作任务；可收藏词卡、复习和查看家长记录。记录保存在当前设备和浏览器。公开静态站点无需登录。

不在当前承诺范围内：跨设备同步、导入记录、真人发音评价或完整自然拼读课程。孩子是否希望增加这些内容，应根据实际使用反馈再决定。

## 核心验收

以下为可观察的验收目标，验证结果见 [进度记录](./progress.md)。

| 前提 | 操作 | 预期结果 | 验证方式 |
| --- | --- | --- | --- |
| 首次打开公开网站 | 在平板或电脑选择一个故事 | 可以进入课程并开始，不需登录 | 浏览器实际操作 |
| 在课程中 | 点击词卡听发音，完成听辨；答错后重试或查看提示 | 有声音或明确的声音问题提示；可继续，不因答错卡住 | 浏览器操作；模拟音频不可用 |
| 在课程中尚未完成 | 查看词卡再返回；尝试退出后取消 | 回到原任务且保留当前进度 | 浏览器实际操作 |
| 完成课程 | 刷新同一浏览器 | 完成记录保留；可再次练习 | 浏览器操作和存储测试 |
| 已有词汇复习记录 | 同一天重复练习或提前练习 | 不因反复操作提前升级；错误可再次复习 | 自动测试与浏览器操作 |
| 打开任一游戏 | 完成一轮并查看反馈 | 游戏可以结束，不计时或扣分；游戏记录不冒充课程完成或单词掌握 | 自动测试与浏览器操作 |
| 本地存储不可用 | 尝试保存进度 | 界面提示记录无法持久保存，仍可继续当次活动 | 自动测试及浏览器模拟 |
| 旧记录损坏或版本不受支持 | 打开网站并尝试保存 | 保留原始记录并提示家长备份；家长确认清空且原记录未发生变化后可重新开始 | 自动测试；浏览器异常流程待验证 |
| 同一浏览器的两个页面都已打开 | 一个页面保存后，另一个页面尝试保存 | 后者提示冲突并停止保存，避免常见的旧页面覆盖；可先导出本页记录 | 自动测试和隔离浏览器操作 |
| 设备较窄或使用键盘 | 完成核心操作 | 内容不横向溢出，主要控件可见、可操作，弹窗可正常关闭 | 手机及平板尺寸、键盘浏览器检查 |

## 以后考虑

先观察孩子是否能独立找到下一步、是否愿意重玩、哪一步最容易受挫，以及实际一次使用多久，再决定内容或功能扩充。正式学习效果需要真实使用样本验证，不以完成次数代替。
